## Project Overview

Single-file generative animation: a WebGL2 fragment shader warps one image (default: the 1943 Bicycle Day poster; kaleidoscope, domain warp, feedback trails, hue/palette cycling) while a Web Audio synth plays generative music. The picture and the sound follow a shared "arc" (intensity over time).
**Stack:** plain HTML/CSS/JS, WebGL2, Web Audio. No runtime dependencies. Node ≥ 18 only for `build.mjs`.

- **ARCS** – the sequential part: keyframe tables `[position, [warp, kal, folds, feedback, hueSpeed, palette, sideDark, breath, melt, zoom, aberration, brightness]]` + `marks` (riser/hit/exhale) + optional `bpm`/`drive`. `score(u)` interpolates; `energy(u)` (0–1) is derived from it and drives heartbeat tempo, drone filter, bells, arpeggios.
- **Engine** – `FS_SCENE` (warp/kaleidoscope/feedback → offscreen FBO ping-pong), `FS_SHOW` (aberration/vignette/grain → screen), `render()`; `buildAudio()` (drone, pads, bells, arps, heartbeat, one-off gestures; rolling `pump()` scheduler).
- **Preset/params** – URL params + gate UI (Energy, Shape = arc (generated music only, precomputed), duration, image). One seed per play (`newSeed()`) drives all randomness.
- **Scene look** – `LOOK`/`CAM`/`PALS`/`LIVE_LOOK`: per-state emphasis, 6 palettes and camera tilt that change on every drop (live) or every ~45 s (generated). `?pal=<0-5>` forces a palette (testing). Don't end a `gl.uniform…` line with a `//` comment: it swallows the rest of the line (this once disabled hue/palette).
- **Live scenes** – `liveStep()` has a section detector (fast vs slow average of level/brightness/bass; a lasting gap or a drop starts a new scene: `LIVE.scenes`, `LIVE.kinds[n]` 1 energetic / 0 calm). The scene sets palette, lead effect, tile grid and a ~3 s transition envelope `tr` (zoom punch, warp, tile burst); the instantaneous state only nudges the look. The arc position `LIVE.u` rises fast and falls slowly so a theme doesn't flicker.
- **Tunnel** – in FS_SCENE `main()` the tunnel (`uTunnel`) renders `layer(p)` (tiles/styles/kaleidoscope/warp/source/code/palette) twice, one log-polar ring apart (`rA`, `rB`), cross-faded over the last 40 % of the ring phase, with analytic gradients (`gX`/`gY`, `textureGrad` in `texI` while `gOn`) so the `fract` wrap neither shows a hard image jump nor picks the coarsest mip. Costs nothing when `uTunnel` is 0. Don't reintroduce a bare `fract()` coordinate before a `texture()`.
- **Quality** – `QUAL` (high/medium/low): internal resolution, canvas DPR, warp layers, colour fringing/grain. Chosen on the home screen / panel, saved in localStorage; software GL (SwiftShader/llvmpipe) defaults to low. `?quality=high|medium|low` forces it.
- **Styles** – opt-in (`USER.style`: off/kali/julia/auto): 2D fractal re-sampling (`kaliFold`, `juliaWarp` in FS_SCENE), inspired by raymarched Shadertoy shaders but written from scratch (no NC-SA code is included). `?style=kali|julia|auto` for tests.
- **Mic input** – `micGain` (GainNode between source and analyser, `MICDB` saved in localStorage `bicycleday.micdb`), `METER` (RMS dBFS from `getFloatTimeDomainData`) drawn in `liveLoop`. Declare any top-level `let/const` used by the UI wiring BEFORE that wiring (TDZ error kills the whole script).
- **Multi-image** – `IM[]` (max 5, #1 = the default picture = the poster, `GALLERY[0]`; the Images drawer is `multiple`, drop works too), `showImg(n)` crossfades ~1.5 s via `uTex2`/`uImgMix` (`texI()` in FS_SCENE; only the source sampling is mixed, the feedback loop is untouched). Keys `V`, `[` / `]` (digits are presets); thumbnail row `#thumbs`.
- **Auto image** – `USER.auto` (0 off / N s / -1 each scene; key `;`, chips `#ais`, `?autoimg=`), `autoImg(dt, scene)` called from `render()`: counts song time by frame steps (never while paused), `begin()`/`startLive()` reset `AI.scene` so a seek can't change the image; `showImg(n, quiet, auto)` — a manual switch resets `AI.acc`.
- **Presets** – tweak values autosave to localStorage (`bicycleday.last`) and 8 slots (`bicycleday.slot1-8`): digits `1..8` recall, `Shift+1..8` save, Load/Save rows in Settings. A slot holds `energy`, `kal`/`tile`/`fb`, `lv` (the per-effect sliders), `auto`, `trans`, `force`, `col`, `src`, `style` and `v: 2` (not seed, music or control level). Old presets (no `v`: `fx`, `inten`) migrate to `energy = round(2 + 2·inten + 2·(fx−1))`.
- **Energy (the user's one picture setting in auto)** – `USER.energy` 0..4 (calm/soft/normal/strong/extreme, default 2), table `EN` = [arc offset, global amount, extreme blend]. Keys Z/X (every level), N = Extreme ↔ previous, chips on the home screen (`#enh`, every source) and the pupitre (`#enp`), `?energy=0..4` (the old `?fx=` and `?hc=1` map onto it). Look only, the music does not change. `UT`: in auto only `off`/`amp` (Energy) count, the sliders (`USER.kal/tile/fb` + `USER.lv.*`) and Colour only apply in assisted/manual (the values stay, switching level gets them back). Persistent state on top of the score, never touched by seek. Mouse: move = kaleidoscope centre, click = ripple, drag = rotate, wheel = zoom (all levels). `?tile=<mode>,<N>` forces the tile effect (testing). `uAt(t, off)` is the pure arc position shared by `render`, `integrateTo`, `integrateLocal`.
- **Surges & moods** – `timelines()` builds seeded, irregular timelines (pure functions of `t`): `surgeAt(t)` = intensity swell (rise 15-30 s, fall 6-15 s, then the image recomposes) scaling warp/kal/Kali/Julia/melt/aberration; `moodAt(t)` = dark / bw / blaze / strobe stretches (blaze also fires at the top of big surges). Mood effects live in `FS_SHOW` (`uDark/uBlaze/uStrobe/uRate`), bw reuses `uMono`. `?mood=dark|bw|blaze|strobe` and `?surge=0..1` force them (testing). Slow start (generated and Local; Live and Extreme skip it): `calm(t)` ramps 0→1 over `rampT()` (generated 50 % of the piece, 20 s–5 min; Local 25 %, 20 s–3 min); it scales surges, zoom swing, source drift, scene/minor punches, zoom pulses and Kali/Julia, and moods only start after the ramp. `FS_SHOW` also does the colour grade (saturation/contrast).
- **Showcase / FX registry** – `?showcase=1[&seg=<sec>]` (default 30 s; same page as `?tune=1`): top-level `const FX = [{name, set(p, k)}]`, one entry per effect. `render()` first builds its final params object `P` (the uniforms read only `P`), then `showcaseParams(P, t)` replaces it with a neutral baseline (plain image) + the active entry (`k` = 0..1 ease in/hold/out; `P.t` = time). Pure function of `t`; `TOTAL = FX.length*seg`. Label `#fxlabel` ("7/28 · name"), ticks on the seek bar (click snaps to an effect start), keys N/P = next/prev. Controlled mode reuses it: adding an effect = its `FX` entry + one `EFFECTS` row (see Control levels). Test: `&quality=high&showcase=1&t=<segment middle>`.
- **Engine bounds (`ENGINE`)** – the limits the generated engine plays inside, as data (`08z-effects.js`): zoom pulse (min/max, durations, gap, pOut), kaleidoscope cap, warp, tiles, tunnel stretches. Code defaults in `ENGINE_DEF`. `?engine=<json>` deep-merges at load (testing). The tuning panel (`09-fx.js`) edits them: sliders, Export JSON, Reset. Its diff is saved in localStorage `bicycleday.engine`, read back only with `?tune=1` or `?showcase=1` (the one page). Every change bumps `ENGINE.v` (caches check it). `?showcase=1` and `?tune=1` are ONE page (T118): the list on the right (`#fxpanel`, all FX entries, clicking / N / P = `fxSelect`) chooses one effect that plays alone on the PF neutral baseline in a loop of `SHOW.seg` = 30 s (`?seg=`); `showcaseParams` draws it. An effect with an engine group (`TUNE_G`: zoom kal warp tile tun glitch rot strobe) is built by `tuneVals(g, lt)` from the group's own ENGINE terms (exactly 0 outside its event; kal/warp use a fixed surge shape, zoom = the real `zoomPulseAt` of one zoom-in, a pause (tune-only, not exported), then one zoom-out via the `TUNE_ZL` hook, rotation = integrated spin from the loop start, glitch fires in every cell, strobe = one stretch) and gets curated sliders (`TUNE_CUR`, plain names, Advanced = every leaf) in the bottom panel `#etune` (chart beside them, Loop / Restart / New draw, Export / Reset); any other effect plays its FX entry and the panel says no sliders. New ENGINE leaves (defaults = the old literals): `glitch` (cell, chance, durMin/durVar, amp/ampVar), `strobe` (rate, dur, amount).
- **Zoom pulses** – `zoomPulseList()` (generated: seeded list, every 30–70 s), `zoomPulseListLocal()` (Local: on scene starts), `zoomPulseLive(t)` (Live: at new scenes, causal, state `LIVE.zp`). `zoomPulseAt(t)` reads the one running. Must fit 1280x720. `#pexp` (▾/▴, far right of `#prow4`) toggles `#pxt`, a text-only explanation panel absolutely positioned above `#pult` (outside the flow, so the pupitre height is unchanged; state in `bicycleday.pexp`, hidden in the home clone).

It drives the `ramp()` of the eased copies `UE.*` (Energy, sliders), `HCr`, the palette/LOOK/style easing and the scene punch decay; `snapLook` forces the first frame after a seek. The pupitre shows the current one.

- **Synth styles** – `STYLES` in `03-arcs.js` (per style: `bpm` range for BEATS, `nohb` = no heartbeat pulse), listed in `MUSICS` after the piano ones. Each style is a `[[STYLE <name>]]` branch of `buildAudio` in `11-sound.js`, built with the shared helpers `MT` ([[MUSIC TOOLS]], pure functions of a seeded rng). Styles: `electro` (dark techno/synthwave, sections intro/drop/break/outro, chords, drums, bass, arp, lead), `chiptune` (8-bit: 2 pulse channels, triangle bass, noise drums), `chiptune2` (richer 8-bit: `MT.period` melody, modes, 3 pulses, fills), `drone` (slow textured sections), `gamelan` (pelog/slendro bronze percussion, colotomic cycle, imbal), `lofi` (`LOFIPLAN`: 70-90 BPM swung 16ths, intro/groove/break/outro, Rhodes-like 7th/9th chords + bass on persistent oscillators with tape wobble, dusty drums, vinyl crackle). `tools/sound-lab.html` = tune voices by ear, exports constants.
- **Minimal style (T22)** – `MUSIC === 'minimal'` (`[[STYLE minimal]]` in `11-sound.js`, Reich / Riley-like): one seeded cell of 8-12 eighths in a mode, fixed tempo (quarter 100-132); every mallet voice plays it: marimba 1 (additive build-up / thinning, one note per cycle), marimba 2 (phasing: drifts one eighth ahead over 2-4 cycles, then locks in), vibraphone (canon n eighths behind; augmentation in breaks), e-piano (chord tones, octave down, drops). Persistent pulse chord (eighths, breath swells, re-enters at each section), bass (drone or pulses) and clarinet/'ooh' pad; one chord per section from a 4-6 chord cycle. Sections intro/build/drop/break/outro from `energy(u)`; `window.MINIMALPLAN`, EVT sections + a `phrase` at each phasing lock-in.
- **Berlin School** – `MUSIC === 'berlin'` (T119, `[[STYLE berlin]]` in `11-sound.js`): no drums, one constant seeded tempo (112-128, its `buildAudio` re-lays `BEATS` on it), one mode per piece. Persistent voices only: sequencer bass (saw+square+sine, resonant lowpass; per-step gate on a VCA, accent on `filter.detune`, cutoff/Q/level curves follow sections + `energy(u)`), a 2nd sequence of another length (6/7/10/12 steps, phasing) in builds/peaks, 3 detuned-saw pad voices with voice leading, a portamento lead (`MT.period`) in breaks and the outro. Pattern mutates per 8 bars. Slow params are `k-rate` (render cost). `window.BERLINPLAN`, events = sections + hit (return after a break) + phrases.
- **Beat grid (T51)** – `USER.grid` 0 beat (old behaviour, default) / 1 bar (scene changes on bar starts = 4 `BEATS`) / 2 phrase (scenes every 8 bars, minors on bars); `gridNb()`/`gridLine()` in `10-control.js`, `vplan()` snaps section starts. Generated ambient/electro/chiptune/chiptune2 only (other styles, Local, Live, Extreme ignore it). Chips `#tgrid` (section Calage of the Source/Settings panel), `?grid=beat|bar|phrase`, `bicycleday.grid`, presets. `__pic(t)` reports `grid`, `gridLine`, `gridDist`.
- **Transport** – `begin(off)` (re)starts sound at song time `off`; `seekTo`, `togglePause` (AudioContext suspend/resume).
- **Live mode (prototype)** – `startLive()` captures a tab's audio via `getDisplayMedia` (Chrome/Edge desktop; `?live=mic` uses the microphone through the same pipeline), `liveStep()` extracts causal features (per-band auto-gain, kicks, build = brightness+level rising, drop = bass slam), produces `LIVE.u`, a position on the `journey` arc, so `render()` reuses all looks. The tab audio is analysed only, never routed to the speakers.
- **Local mode** – `loadLocal()` decodes a file (OfflineAudioContext, 44.1 kHz), `analyseLocal()` runs the `liveStep()` features/detectors offline (FFT 2048, 40 fps, zero-phase smoothing, back-dated scene starts, 0.25 s look-ahead) into a timeline; `localView(t)` writes it into the LIVE-shaped object (`LOC` = active timeline, `LIVE` = view) so `render()` is untouched and the picture stays a pure function of `t`; `integrateLocal()` is the seek fast-forward; The local intensity `I` follows ABSOLUTE loudness: `ag` = raw band energy vs the track's 95th percentile; `u = lerp(.04,.88,I*ag-gate)` fades in over 6 s, and tension/boost, scene and minor punches are suppressed while `ag` < .3 (a quiet intro stays still). `playLocal()` plays the buffer (`TOTAL` = file length). `?local=<url>` (needs http, `fetch`) plays it, with `&t=` renders a still.

- **Next track (Local)** – `NEXT` (chosen File, picker on the start screen `#nextpick` and in Settings `#tnext`), `prepNext()` decodes/analyses it in the background (`decodeLocal`, no UI side effects) into `NEXTDATA`; at the end of the track (or `playNextNow()` / `#nextnow`) `loop()` calls `goNext()` (swap `LOC`, `begin(0, true)`); if the analysis is not done it waits ("Loading next track…"), `NEXTFAIL` shows an error and the piece ends normally.
- **Home screen** – a full-screen logo + nav (Play / Images / Settings / Help) and a drawer (`homePanel`, `homeGate(open)` also sets `inert`). The logo is drawn by its own small WebGL path (`homeFrame(t)`, constants `HOME_*`, own programs from FS_SCENE/FS_SHOW with mild parameters): still 0-5 s, slight 5-15 s, then a slow ramp to a gentle level (`?hometime=<s>` fixes the clock for screenshots). Its loop runs only while the gate is open and never touches audio, `IM[]`, `USER` or the main render loop.

## Invariants (don't break)

- The picture is a pure function of the audio clock time `t` (`render(t, dt, …)`). Drifting state (`hue`, `rotA`) is integrated per frame and re-derived by `integrateTo(off)` on seek — keep both in sync when changing `render()`.
- Anything added to the **feedback loop** (pass 1) accumulates frame after frame. One-shot flashes (pulse) must be added in the display pass, not pass 1 (this once blew the image out to white).
- Strobe is allowed on purpose (owner's call: tool for people used to fast visuals, not for children): the `strobe` mood flashes full-screen white/dark at 5-11 Hz for 6-14 s. Keep it in the display pass only (never pass 1) so it can't accumulate in the feedback loop.
- The default image (the poster, `GALLERY[0]`) and the home logo must be inlined as data URIs (WebGL rejects `file://` images as textures); `build.mjs` inlines the logo once in the home `<img>` (`IMG` reads that `src`, home screen only) and the gallery into `GALLERY`. User images go through `URL.createObjectURL`, which is fine.

## Testing without a GPU / speakers

Headless Chrome with software GL renders a still at time `t` by stepping the feedback loop silently:

```bash
google-chrome --headless=new --no-sandbox --use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader \
  --window-size=1920,1080 --virtual-time-budget=120000 --screenshot=/tmp/f.png \
  "file://$PWD/dist/bicycle-day.html?t=200&res=.3&step=.5&arc=intense&seed=3"
```

`res` shrinks the offscreen buffer, `step` is the simulated frame step (bigger = faster, less exact). Live mode can be tested with real-time fake input: playwright chromium with `--use-fake-device-for-media-stream --use-fake-ui-for-media-stream --use-file-for-fake-audio-capture=track.wav`, open `?live=mic&debug=1` and read the `LIVE t=…` console lines (state sequence should follow the track's structure). Audio can't be heard this way: smoke-test it by auto-calling `start()` with `--autoplay-policy=no-user-gesture-required` and checking the console for errors.

- `?debug=1` (stills): `window.__plog` = P sampled every 0.5 s of song time; `python3 tools/measure.py` turns it into effect-usage tables per source (generated, Local; Live is real-time only).
- `?debug=1`: `window.__pic(t)` = what the picture does at song time t (scene, punch, surge, mood, `zoomPulse`, `TRN`, `engineV`, `srcGain`). Read only.
- `python3 tools/check.py` (full) and `python3 tools/smoke.py` (real home flow) are the checks; see Tickets.
