**Before any ticket**, read `.tickets/WORKFLOW.md`. Modules used here: `.tickets/modules/worktrees.md` and `.tickets/modules/roles.md`.

**Status, decisions and calibration results: kept outside this repo (private notes); the architecture and invariants below are self-contained.**

## Project Overview

Single-file generative animation: a WebGL2 fragment shader warps one image (default: the 1943 Bicycle Day poster; kaleidoscope, domain warp, feedback trails, hue/palette cycling) while a Web Audio synth plays generative music. The picture and the sound follow a shared "arc" (intensity over time).
**Stack:** plain HTML/CSS/JS, WebGL2, Web Audio. No runtime dependencies. Node ≥ 18 only for `build.mjs`.

Edit `src/js/*.js` (app code, one file per section) and `src/index.html` (markup + CSS), never `dist/` (generated; committed on purpose so it opens without a build).

- **ARCS** – the sequential part: keyframe tables `[position, [warp, kal, folds, feedback, hueSpeed, palette, sideDark, breath, melt, zoom, aberration, brightness]]` + `marks` (riser/hit/exhale) + optional `bpm`/`drive`. `score(u)` interpolates; `energy(u)` (0–1) is derived from it and drives heartbeat tempo, drone filter, bells, arpeggios.
- **Engine** – `FS_SCENE` (warp/kaleidoscope/feedback → offscreen FBO ping-pong), `FS_SHOW` (aberration/vignette/grain → screen), `render()`; `buildAudio()` (drone, pads, bells, arps, heartbeat, one-off gestures; rolling `pump()` scheduler).
- **Preset/params** – URL params + gate UI (Energy, Shape = arc (generated music only, precomputed), duration, image). One seed per play (`newSeed()`) drives all randomness.
- **Scene look** – `LOOK`/`CAM`/`PALS`/`LIVE_LOOK`: per-state emphasis, 6 palettes and camera tilt that change on every drop (live) or every ~45 s (generated). `?pal=<0-5>` forces a palette (testing). Don't end a `gl.uniform…` line with a `//` comment: it swallows the rest of the line (this once disabled hue/palette).
- **Live scenes** – `liveStep()` has a section detector (fast vs slow average of level/brightness/bass; a lasting gap or a drop starts a new scene: `LIVE.scenes`, `LIVE.kinds[n]` 1 energetic / 0 calm). The scene sets palette, lead effect, tile grid and a ~3 s transition envelope `tr` (zoom punch, warp, tile burst); the instantaneous state only nudges the look. The arc position `LIVE.u` rises fast and falls slowly so a theme doesn't flicker. Glitch (T152, Live and Local; T153 Extreme too, with `pSceneX` / `pLiveX` / `cellX` = more bursts): `glitchLive(t)` (`08-director.js`) = a burst just after an energetic scene starts (`ENGINE.glitch.pScene`) + the generated cell bursts at `pLive` while the scene is energetic and not calm / breakdown; a pure function of t, scaled by `UE.big`.
- **Tunnel** – in FS_SCENE `main()` the tunnel (`uTunnel`) renders `layer(p)` (tiles/styles/kaleidoscope/warp/source/code/palette) twice, one log-polar ring apart (`rA`, `rB`), cross-faded over the last 40 % of the ring phase, with analytic gradients (`gX`/`gY`, `textureGrad` in `texI` while `gOn`) so the `fract` wrap neither shows a hard image jump nor picks the coarsest mip. Costs nothing when `uTunnel` is 0. Don't reintroduce a bare `fract()` coordinate before a `texture()`.
- **Quality** – `QUAL` (high/medium/low): internal resolution, canvas DPR, warp layers, colour fringing/grain. Chosen on the home screen / panel, saved in localStorage; software GL (SwiftShader/llvmpipe) defaults to low. `?quality=high|medium|low` forces it.
- **Styles** – opt-in (`USER.style`: off/kali/julia/auto): 2D fractal re-sampling (`kaliFold`, `juliaWarp` in FS_SCENE), inspired by raymarched Shadertoy shaders but written from scratch (no NC-SA code is included). `?style=kali|julia|auto` for tests. **Shape (T163)**: `ENGINE.kali` {`zoom` input scale, `iter`, `scale` fold scale} and `ENGINE.julia` {`zoom`, `iter`, `drift` of c} reach `FS_SCENE` as `uKaliP` / `uJuliaP` (vec3; loops run to a fixed max with a `break` at `iter`), `ENGINE.kal.zoom` as `uKalZ` (multiplies the radius in `kal()`). Smaller zoom = closer = bigger shapes, less fine detail; defaults are closer than the old fixed look (Kali 1.4 -> .8, Julia .7 -> .45, kaleidoscope 1 -> .85, Julia 6 -> 5 iterations). The home logo keeps the old fixed shapes (its own uniforms).
- **Mic input** – `micGain` (GainNode between source and analyser, `MICDB` saved in localStorage `bicycleday.micdb`), `METER` (RMS dBFS from `getFloatTimeDomainData`) drawn in `liveLoop`. Declare any top-level `let/const` used by the UI wiring BEFORE that wiring (TDZ error kills the whole script).
- **Multi-image** – `IM[]` (max 5, #1 = the default picture = the poster, `GALLERY[0]`; the Images drawer is `multiple`, drop works too), `showImg(n)` crossfades ~1.5 s via `uTex2`/`uImgMix` (`texI()` in FS_SCENE; only the source sampling is mixed, the feedback loop is untouched). Keys `[` / `]` (V / B = Calm; digits are presets); thumbnail row `#thumbs`. **Image change = masked morph (T167)**: `USER.morph` (1 default / 0 = the plain 1.5 s crossfade; chips Image change in Settings, `bicycleday.morph`, `?morph=0|1`). `showImg()` draws style (crossfade / organic dissolve / iris / colour first), seed, duration and stages ONCE from `seedHash(MORPH.n, ..)` (`morphDraw`, 10-60 s at Energy calm / soft, 4-30 s normal, 3-15 s strong / Extreme, at every control level (showcase 1.5 s), Extreme = crossfade style; half of the long ones in two stages, `morphM`); `imMix += dt / MORPH.dur` stays, `uImgMix` = m (the staged B share) and `texI()` (`05-shaders.js`) turns it into a per-sample `k = smoothstep(s - w, s + w, m(1+2w) - w)` from the mirrored image uv (`morphS`, cheap: no tap loops; colour first = A's mean / std move to B's, stats from a 64x64 copy at load `IM[n].st`, then an organic reveal). A switch mid-morph starts from the image with the larger share. Log line `morph: image 2 -> 3 · iris · 34 s`, `__pic(t).morph` = { on, style, m, dur, from, to } or null.
- **Auto image** – `USER.auto` (0 off / N s / -1 each scene; key `;`, chips `#ais`, `?autoimg=`), `autoImg(dt, scene)` called from `render()`: counts song time by frame steps (never while paused), `begin()`/`startLive()` reset `AI.scene` so a seek can't change the image; `showImg(n, quiet, auto)` — a manual switch resets `AI.acc`.
- **Presets** – tweak values autosave to localStorage (`bicycleday.last`) and 8 slots (`bicycleday.slot1-8`): digits `1..8` recall, `Shift+1..8` save, Load/Save rows in Settings. A slot holds `energy`, `kal`/`tile`/`fb`, `lv` (the per-effect sliders), `auto`, `trans`, `force`, `col`, `src`, `style` and `v: 2` (not seed, music or control level). Old presets (no `v`: `fx`, `inten`) migrate to `energy = round(2 + 2·inten + 2·(fx−1))`.
- **Energy (the user's one picture setting in auto)** – `USER.energy` 0..4 (calm/soft/normal/strong/extreme, default 2), table `EN` = [arc offset, global amount, extreme blend]. Persistent state on top of the score, never touched by seek. Mouse: move = kaleidoscope centre, click = ripple, drag = rotate, wheel = zoom (all levels). `?tile=<mode>,<N>` forces the tile effect (testing). `uAt(t, off)` is the pure arc position shared by `render`, `integrateTo`, `integrateLocal`.

- **Control levels** – `CL` 0 auto / 1 assisted / 2 manual (`CTRL` = manual), independent of the music source (key M, chips `#lvl` home, `#lvls` Settings, `#plvl` pupitre, `bicycleday.level`, `?level=`, `?ctrl=1`; showcase forces 0). **Auto: the engine decides everything except Energy, images, camera, presets and tools**; a single gate in the keydown handler (`AUTO_OK`) answers other keys with `hintAuto()`. `ctrlParams(P,t,dt)` runs when `CL`: manual replaces the engine's P by `QUIET` (+ small breath/heartbeat/drift) — all halved on 2026-10-17 (warp .06, breath .6, aberration .05, heartbeat ×.3, auto rotation ×.25, zoom/tilt drift halved; hue drift unchanged) because sliders at 0 still looked too lively, assisted keeps P; every `CT_KEYS` row runs its `FX` entry on a scratch copy and only the delta is added, eased 0.5-0.8 s, scaled by its slider (`lvOf(e)`); manual strength = `.4 + 1.2·Energy/4`; assisted toggles switch off after their life (`lifeDraw()`: `USER.hold` 0 = random 4.5-15 s drawn per press, 31 = never; slider `#u-hold`, saved in presets), held rows (G J Enter) stay while held, palette C lets go too. Showcase: 4 FX entries (`mood: strobe, accelerating / negative`, `strobe grid, colour / accelerating`; `?fxi=<n>` starts on entry n). `codeFeed`: `strobe: negative`, `checkerboard: colour`, `... accelerating`; `__pic(t).svar` (name, phase) and `.acc.variant`. Live-coding `CODE`/`codeFeed(P)` (key L cycles off/log/overlay/crazy, `bicycleday.code` 0-3, `?code=`) only reads P. - **Piano music** – `MUSIC` (piano choices gnossienne/gnossienne3/tempest/gymnopedie; `ambient` = the generated default; chips `#mus`, localStorage `bicycleday.music`, `?music=` for tests). - **Synth styles** – `STYLES` in `03-arcs.js` (per style: `bpm` range for BEATS, `nohb` = no heartbeat pulse), listed in `MUSICS` after the piano ones. Each style is a `[[STYLE <name>]]` branch of `buildAudio` in `11-sound.js`, built with the shared helpers `MT` ([[MUSIC TOOLS]], pure functions of a seeded rng). Rules: sustained voices are PERSISTENT oscillators driven by automation; per-note nodes only for short hits (mallets, plucks) under a voice budget, the whole plan is drawn from the seed (pure function of seed + bar/time, so a seek just resumes), the plan is published as `window.<X>PLAN` (`CHIPPLAN`, `ELECTRO_PLAN`, `DRONEPLAN`, `GAMELANPLAN`) plus `evtSet` events that `vplan()` reads so the picture changes scene with the sections; the `TRIM` line sets the style's level. Styles: `electro` (dark techno/synthwave, sections intro/drop/break/outro, chords, drums, bass, arp, lead), `chiptune` (8-bit: 2 pulse channels, triangle bass, noise drums), `chiptune2` (richer 8-bit: `MT.period` melody, modes, 3 pulses, fills), `drone` (slow textured sections), `gamelan` (pelog/slendro bronze percussion, colotomic cycle, imbal), `lofi` (`LOFIPLAN`: 70-90 BPM swung 16ths, intro/groove/break/outro, Rhodes-like 7th/9th chords + bass on persistent oscillators with tape wobble, dusty drums, vinyl crackle). `tools/sound-lab.html` = tune voices by ear, exports constants.
- **Minimal style (T22)** – `MUSIC === 'minimal'` (`[[STYLE minimal]]` in `11-sound.js`, Reich / Riley-like): one seeded cell of 8-12 eighths in a mode, fixed tempo (quarter 100-132); every mallet voice plays it: marimba 1 (additive build-up / thinning, one note per cycle), marimba 2 (phasing: drifts one eighth ahead over 2-4 cycles, then locks in), vibraphone (canon n eighths behind; augmentation in breaks), e-piano (chord tones, octave down, drops). Persistent pulse chord (eighths, breath swells, re-enters at each section), bass (drone or pulses) and clarinet/'ooh' pad; one chord per section from a 4-6 chord cycle. Sections intro/build/drop/break/outro from `energy(u)`; `window.MINIMALPLAN`, EVT sections + a `phrase` at each phasing lock-in.
- **Berlin School** – `MUSIC === 'berlin'` (T119, `[[STYLE berlin]]` in `11-sound.js`): no drums, one constant seeded tempo (112-128, its `buildAudio` re-lays `BEATS` on it), one mode per piece. Persistent voices only: sequencer bass (saw+square+sine, resonant lowpass; per-step gate on a VCA, accent on `filter.detune`, cutoff/Q/level curves follow sections + `energy(u)`), a 2nd sequence of another length (6/7/10/12 steps, phasing) in builds/peaks, 3 detuned-saw pad voices with voice leading, a portamento lead (`MT.period`) in breaks and the outro. - **Local mode** – `loadLocal()` decodes a file (OfflineAudioContext, 44.1 kHz), `analyseLocal()` runs the `liveStep()` features/detectors offline (FFT 2048, 40 fps, zero-phase smoothing, back-dated scene starts, 0.25 s look-ahead) into a timeline; `localView(t)` writes it into the LIVE-shaped object (`LOC` = active timeline, `LIVE` = view) so `render()` is untouched and the picture stays a pure function of `t`; `integrateLocal()` is the seek fast-forward; The local intensity `I` follows ABSOLUTE loudness: `ag` = raw band energy vs the track's 95th percentile; `u = lerp(.04,.88,I*ag-gate)` fades in over 6 s, and tension/boost, scene and minor punches are suppressed while `ag` < .3 (a quiet intro stays still). `playLocal()` plays the buffer (`TOTAL` = file length). `?local=<url>` (needs http, `fetch`) plays it, with `&t=` renders a still.

## Invariants (don't break)

- The picture is a pure function of the audio clock time `t` (`render(t, dt, …)`). Drifting state (`hue`, `rotA`) is integrated per frame and re-derived by `integrateTo(off)` on seek — keep both in sync when changing `render()`.
- Anything added to the **feedback loop** (pass 1) accumulates frame after frame. One-shot flashes (pulse) must be added in the display pass, not pass 1 (this once blew the image out to white).
- Strobe is allowed on purpose (owner's call: tool for people used to fast visuals, not for children): the `strobe` mood flashes full-screen white/dark at 5-11 Hz for 6-14 s. Keep it in the display pass only (never pass 1) so it can't accumulate in the feedback loop.
- The default image (the poster, `GALLERY[0]`) and the home logo must be inlined as data URIs (WebGL rejects `file://` images as textures); `build.mjs` inlines the logo once in the home `<img>` (`IMG` reads that `src`, home screen only) and the gallery into `GALLERY`. User images go through `URL.createObjectURL`, which is fine.

## Testing without a GPU / speakers

Headless Chrome with software GL renders a still at time `t` by stepping the feedback loop silently:

```bash
google-chrome --headless=new --no-sandbox --use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader \
  --window-size=1920,1080 --virtual-time-budget=120000 --screenshot=/tmp/f.png \
  "file://$PWD/dist/bicycle-day.html?t=200&res=.3&step=.5&arc=intense&seed=3"
```

`res` shrinks the offscreen buffer, `step` is the simulated frame step (bigger = faster, less exact). Live mode can be tested with real-time fake input: playwright chromium with `--use-fake-device-for-media-stream --use-fake-ui-for-media-stream --use-file-for-fake-audio-capture=track.wav`, open `?live=mic&debug=1` and read the `LIVE t=…` console lines (state sequence should follow the track's structure). Audio can't be heard this way: smoke-test it by auto-calling `start()` with `--autoplay-policy=no-user-gesture-required` and checking the console for errors.

- `?debug=1` (stills): `window.__plog` = P sampled every 0.5 s of song time; `python3 tools/measure.py` turns it into effect-usage tables per source (generated, Local); Live: `tools/measure_live.py <wav>` (real time, one run per Energy x seed).
- `?debug=1`: `window.__pic(t)` = what the picture does at song time t (scene, punch, surge, mood, `zoomPulse`, `TRN`, `engineV`, `srcGain`). Read only.
